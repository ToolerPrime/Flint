# Porting PhotoCraft's colour picker and brushes to Flint

Looked at 2026-11-08. Source: https://github.com/storytold/photocraft (ArtCraft's
photo editor, pure Rust, egui UI).

## Can we use it?

Yes. The code is MIT or Apache-2.0 (our choice). We may copy and translate it,
as long as we keep the copyright notice: add an entry to `CREDITS_LICENSES.md`
("Portions translated from PhotoCraft, Copyright (c) 2026 ArtCraft Team and the
PhotoCraft contributors, MIT License") and keep a short comment at the top of
each ported file.

Not allowed: the ArtCraft name, wordmark and logos (`docs/brand/`, trademarks).
The brushes need no files: the built-in tips and textures are generated by code
(`crates/paint/src/procedural.rs`, "no bundled brush files").

## What PhotoCraft has

**Colour picker** (`crates/ui-egui/src/dialogs/color_picker_ui.rs`, about 1,100
lines): a copy of Photoshop's Color Picker. A big 2D colour field plus a slider
for one chosen channel (radio buttons H, S, B, R, G, B, and Lab L, a, b), new and
current swatches, out-of-gamut and web-safe warnings, HSB, RGB, Lab, CMYK and
hex fields, and the canvas works as an eyedropper while it is open.

**Brush engine** (`crates/paint/src/`, about 13,000 lines with tests): a copy of
Photoshop's brush system.
- Tip: round (size, hardness, angle, roundness, flip) or a greyscale picture tip.
- Spacing, opacity, flow, build-up (airbrush), wet edges, noise, smoothing.
- Dynamics sections, each optional: shape (size, angle and roundness jitter),
  scattering, texture, dual brush, colour dynamics, transfer (opacity and flow
  jitter). Each can follow pen pressure, tilt, fade or direction.
- Mixer brush (wet paint mixing) and retouch dabs.
- 37 presets in 4 groups: General (hard/soft round, airbrush, calligraphy),
  Dry Media (pencil, chalk, charcoal, pastel, crayon, bristle, rake), Wet Media
  (watercolour, ink, oil, gouache, sponge), Special Effects (spatter, stipple,
  confetti, foliage, grass, sparkle, textures, halftone).

## What Flint has today

- Colours: the plain Windows colour dialog, in 4 places (main swatches, effect
  colours, object properties, GIF optimiser matte).
- Painting: a hard 1-pixel-exact pencil with a size, and an eraser. No soft
  brushes, no pressure, no presets.

## Plan (each phase is a separate, testable step)

1. **Colour picker** — done 2026-11-08 (`desktop/ColourPickerDialog.cs`, `--colourtest`). Lab and CMYK left out. Translate the dialog to a WinForms
   `ColourPickerDialog`: 2D field + slider, H/S/B/R/G/B radio modes, new/current
   swatches, HSB/RGB/hex fields, web-safe warning, eyedropper on the canvas.
   Lab and CMYK fields only if cheap. Replace all 4 `ColorDialog` uses. Test:
   colour maths round trips (RGB to HSB and back, hex parsing), field position
   to colour for each mode.
2. **Brush engine core** — done 2026-11-08 (`desktop/BrushEngine.cs`, `MainForm.Brush.cs`, `--brushtest`). Build-up over time (airbrush hold) left for phase 3. round tip with size, hardness, angle, roundness,
   spacing, opacity, flow, build-up; dabs placed along the stroke; one stroke
   buffer so opacity caps a stroke the way Photoshop does. Written as byte
   operations (Flint's exact-pixel rule: no GDI+ drawing on stored pixels).
   The existing pencil stays for pixel art; the brush is a new tool (B), and
   the pencil keeps Y.
3. **Dynamics** — done 2026-11-08 except pen pressure (`BrushSettingsDialog.cs`): brush blend mode and Behind, shape dynamics, scattering, colour dynamics, transfer, noise, wet edges, build-up, smoothing. Original plan: shape, scattering, transfer, colour dynamics; pen pressure
   through Windows pointer messages (WM_POINTER) when a tablet is present.
4. **Presets and picture tips**: the 37 presets with the generated tips and
   textures from `procedural.rs`, a brush panel with previews, save/load.
5. **Later, only if wanted**: texture, dual brush, wet edges, mixer brush.

Each phase: tests in a `--` suite, full suite passing, live window check.
